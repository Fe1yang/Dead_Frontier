## 2. 构建流程（照抄即可）

```powershell
# 1) 同步真理源 -> 克隆（排除 .git/.godot/.github 与美术源文件）
robocopy $truth $clone /MIR /XD "$truth\.git" "$clone\.git" "$truth\.godot" "$clone\.godot" `
  "$truth\.github" "$clone\.github" "$truth\.venv-model" "$truth\assets\blender" "$truth\assets\models\source"

# 2) ⚠️ 必须手动把构建号 +1（最容易忘，忘一次 Apple 就静默丢弃整包）
#    export_presets.cfg -> application/version="N+1"（真理源 + 克隆都要改）

# 3) 提交推送
git -C $clone add -A; git -C $clone commit -m "..."; git -C $clone push origin main

# 4) 触发构建（workflow_dispatch，push 不会自动触发）
$token = (git -C $clone credential fill <<< "protocol=https`nhost=github.com`n" | Select-String '^password=') # 实际用 curl + JSON 文件
curl.exe -X POST -H "Authorization: Bearer $token" -H "Accept: application/vnd.github+json" `
  -H "Content-Type: application/json" --data-binary "@body.json" `
  https://api.github.com/repos/Fe1yang/Dead_Frontier/actions/workflows/build-ios-signed.yml/dispatches
# body.json = {"ref":"main","inputs":{"crash_offsets":""}}
```

- 构建约 15–20 分钟；`Build IAP plugin from source` 是最慢的一步
- 上传后我加了自动步骤：保留 dSYM + `atos` 翻译 + 上传 artifact（`DeadFrontier-dsym`）
- **注意**：`curl -d` 在 PowerShell 里会被引号搞坏，必须 `--data-binary "@文件"`

## 3. 崩溃：已诊断到函数级

三次崩溃，三个不同调用点，**同一个根因**：

| 构建 | 崩溃函数 | 含义 |
|---|---|---|
| 4 | `Node::get_children` | 对 null 遍历子节点 |
| 5（第一次） | `Node::find_children` | 对 null 查子节点 |
| 5（第二次） | `Node::find_child` | 对 null 查单节点 |

调用形态一致：

```
GDScript _ready() -> 辅助函数 -> null.find_child(...)
  <- MethodBindTRC::validated_call
  <- GDScriptFunction::call
  <- Node::_notification(READY)
  <- Node::_propagate_ready
  <- Node::_set_tree
  <- -[GDTViewRenderer setupView:]   (引擎首帧)
```

**根因**：iOS 真机上 `load()` 返回 null（Windows 本机因为 `.godot` 缓存齐全永远不会复现），
代码没判空直接 `.instantiate()` / `find_child()` → 空指针段错误。

**已修**（`8214c3d`）：
- 新增 `ModelFix.spawn(path)`，所有运行时模型加载统一走它，失败返回 null
- 6 处调用点改造：`player_3d`、`zombie_3d`、`corpse_3d`、`lootbox_scene_3d`、`pet_companion_3d`、`boss_chaser_3d`
- 拿到 null 就 `return`，游戏继续跑（少一个模型，不闪退）

## 4. 无 Mac 符号化（关键能力，务必保留）

```powershell
# 1) 取某次构建的 dSYM artifact（不需要 Actions 额度，普通 API 即可）
curl.exe -sL -H "Authorization: Bearer $token" -H "Accept: application/vnd.github+json" `
  -H "User-Agent: dsh" -o dsym.zip <artifact.archive_download_url>
# 解压两层：dsym.zip -> DeadFrontier-symbols.zip -> dSYMs/DeadFrontier.app.dSYM/Contents/Resources/DWARF/DeadFrontier

# 2) 用 Python 解析 Mach-O 符号表（不需要 macOS/atos）
python crash\macho_sym.py <DWARF 文件> "0x15174b4 0x152fbec ..."

# 3) 解析 .ips 拿到偏移与 UUID
python crash\parse_ips.py <xxx.ips>
```

- 崩溃报告里的 `slice_uuid` 必须与 dSYM 的 UUID 一致（本机三次都是 `14DEBE00-...`）
- 映射公式：`符号地址 = 0x100000000 + imageOffset`
- 已有工具：`crash/parse_ips.py`、`crash/parse_ips.py`、`crash/patch_*.py`、`crash/asc_builds.js`
